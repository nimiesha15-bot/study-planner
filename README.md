# Studyday — Study Planner

A calm, responsive study planner you can use in your browser. Add assignments and study sessions, keep track of due dates, and check off work as you finish it.

## Features

- Add tasks with an optional subject and due date
- Filter tasks by all, to do, or done
- Mark tasks complete and see your progress
- View dates with planned tasks in the weekly overview
- Switch between light and dark themes
- Saves tasks and theme preference in your browser using local storage
- Responsive layout for desktop and mobile

## Run it locally

No build tools or dependencies are required. Download or clone this repository, then open the index.html file in a modern browser.

## Publish with GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages** in the left menu.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the main branch and the root folder, then save.
5. GitHub Pages will show the published site URL on the Pages settings screen once it is ready.

Tasks are stored on the device and browser where you use the site. They are not synced between devices.
